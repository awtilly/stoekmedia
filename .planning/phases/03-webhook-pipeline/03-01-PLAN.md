  <action>
Add a new `exports.boldSignWebhook` using `onRequest` (not onCall) from `firebase-functions/v2/https` to the existing `functions/index.js`. Add `const { onRequest } = require("firebase-functions/v2/https");` alongside the existing onCall import (destructure both from the same require). Add `const crypto = require("crypto");` and `const { getStorage } = require("firebase-admin/storage");` at the top.

The function implements a linear pipeline:

**Step 1 -- Method guard:** Only accept POST. Return 405 for other methods.

**Step 2 -- HMAC verification (WHBK-02):** Parse the `X-BoldSign-Signature` header (lowercase in req.headers). Header format: `t=timestamp, s0=signature`. Construct signed payload as `timestamp + "." + req.rawBody.toString("utf8")`. Compute HMAC-SHA256 using `process.env.BOLDSIGN_WEBHOOK_SECRET`. Compare with `crypto.timingSafeEqual` (hex buffers). If invalid or missing, return `res.status(401).send("Invalid signature")`. Log: `console.error("Webhook signature verification failed")`.

**Step 3 -- Event filtering (WHBK-03):** Parse body. Check `req.body.event.eventType === "Completed"` (capital C, case-sensitive). If not Completed, return `res.status(200).send("OK")` immediately. This is a locked user decision.

**Step 4 -- Document lookup (WHBK-04):** Extract `documentId` from `req.body.data.documentId`. Use `db.collectionGroup("complianceDocs").where("boldSignDocumentId", "==", documentId).limit(1).get()`. If snapshot is empty, log warning and return 200 (don't retry for unknown docs). Extract `clientId` from `docSnap.ref.parent.parent.id`, `templateId` from `docSnap.id`, and read `sentBy` from docSnap data for the realtorId. Also read the template name from `documentTemplates/{templateId}` for filename construction.

**Step 5 -- Idempotency check (WHBK-09):** Before downloading, check if `files/${clientId}_signed_${templateId}` already exists. If it does, return 200 immediately (duplicate event). Use deterministic document IDs following the Phase 1 pattern.

**Step 6 -- Download signed PDF (WHBK-05):** GET `https://api.boldsign.com/v1/document/download?documentId=${encodeURIComponent(documentId)}` with `X-API-KEY: process.env.BOLDSIGN_API_KEY`. Check `response.ok`. Convert to Buffer via `Buffer.from(await response.arrayBuffer())`. On failure, log error and return 200 (don't make BoldSign retry if their own download endpoint has issues -- it would just fail again).

**Step 7 -- Upload to Storage (WHBK-06):** Construct filename as `{TemplateName}_signed_{YYYY-MM-DD}.pdf` (spaces in template name replaced with underscores). Storage path: `clients/${clientId}/closing-documents/${filename}`. Use `getStorage().bucket().file(storagePath).save(pdfBuffer, { contentType: "application/pdf" })`. After upload, get a signed URL with `file.getSignedUrl({ action: "read", expires: "2030-01-01" })`.

**Step 8 -- Write Firestore records (WHBK-07, WHBK-08):** Run these in parallel with `Promise.all`:
  - File record: `db.doc("files/" + clientId + "_signed_" + templateId).set({...})` with fields: clientId, realtorId (from sentBy), fileName, storagePath, downloadUrl (signed URL), folderId (`${clientId}_closing_documents`), fileSize (pdfBuffer.length), mimeType "application/pdf", signedSource: true, signedAt: FieldValue.serverTimestamp(), complianceTemplateId: templateId, boldSignDocumentId: documentId, uploadedAt: FieldValue.serverTimestamp().
  - Status update: `db.doc("clients/" + clientId + "/complianceDocs/" + templateId).update({ status: "signed", signedAt: FieldValue.serverTimestamp() })`.

**Step 9 -- Respond (WHBK-10):** Return `res.status(200).send("OK")`.

**Error handling:** Wrap the entire pipeline (steps 4-8) in try/catch. On any error, log with `console.error("boldSignWebhook error:", error)` and still return 200 (to prevent BoldSign from retrying a permanently failing request). Steps 1-3 (method guard, HMAC, event filter) are outside the try/catch since they are quick rejects.

**Region:** Set `{ region: "us-central1" }` in the onRequest options to match existing functions.

**IMPORTANT:** Do NOT modify or remove the existing `createSenderIdentity`, `resolveServerMergeFields`, `sendComplianceDoc`, or `sendBulkComplianceDocs` exports. Add `boldSignWebhook` below them.
