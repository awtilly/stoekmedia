**buildMergeFields function:**

```javascript
export function buildMergeFields(template, clientData, listingData, agentProfile) {
  // template: documentTemplates document with mergeFields array
  // clientData: client Firestore doc data
  // listingData: listing Firestore doc data (may be null)
  // agentProfile: users/{uid} Firestore doc data
  //
  // Returns: { existingFormFields: [{id, value}], missing: [string] }
}
```

Implementation (matching research pattern):
- Build a `sources` object: `{ client: clientData || {}, listing: listingData || {}, agent: agentProfile || {} }`
- For each field in `template.mergeFields`:
  - If source is "date", resolve to `new Date().toLocaleDateString("en-US")`
  - Otherwise, split `field.source` by "." to get [sourceKey, ...pathParts]
  - Walk the path to resolve the value: `sources[sourceKey]?.[part1]?.[part2]` etc.
  - Convert to string if non-null, empty string if null/undefined
  - Track missing fields (where resolved value is empty) by adding `field.boldSignFieldId` to missing array
- Return `{ existingFormFields, missing }`
