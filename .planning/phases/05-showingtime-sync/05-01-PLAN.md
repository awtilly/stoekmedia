4. **Add syncFeedForUser internal helper** (not exported -- shared by both callable and scheduled):
   - Accept `(realtorId, feedUrl)` parameters
   - Normalize URL: `feedUrl.replace(/^webcal:\/\//i, "https://")`
   - Require and call `ical.async.fromURL(url)` wrapped in try/catch
   - On fetch error: update `users/{realtorId}` with `showingTimeSyncError: err.message`, then re-throw
   - Filter results for entries where `type === 'VEVENT'` and `status !== 'CANCELLED'` (case-insensitive)
   - Build `feedEvents` map: `sanitizedUid -> event`
   - Query existing ST showings: `db.collection("showings").where("realtorId", "==", realtorId).where("source", "==", "showingtime").get()`
   - Use `db.batch()` for all writes:
     - Upsert each feed event with deterministic ID `st_${realtorId}_${sanitizedUid}` using `batch.set(docRef, {...}, { merge: true })`. Fields: realtorId, source: "showingtime", icalUid, address (from event.summary || event.location || "ShowingTime Showing"), showingDate (Timestamp from event.start), endDate (Timestamp from event.end), location, description, status: "scheduled", icalSequence, updatedAt: FieldValue.serverTimestamp(). On first insert also set createdAt (use merge:true so createdAt is only written once).
     - Delete existing docs whose icalUid (sanitized) is NOT in feedEvents map
   - Handle batch limit of 500: if total operations > 450, chunk into separate batches
   - After batch commit: update `users/{realtorId}` with showingTimeLastSyncedAt: FieldValue.serverTimestamp(), showingTimeSyncError: null, showingTimeSyncCount: upsertCount
   - Return `{ synced: upsertCount, removed: deleteCount }`

5. **Add syncShowingTime callable** (onCall):
   - Region: us-central1
   - Require auth (`request.auth`)
   - Read user doc to get `showingTimeFeedUrl`
   - Validate feed URL exists, throw HttpsError("failed-precondition") if not
   - Rate limit check: read `showingTimeLastSyncedAt`, if less than 15 minutes ago, throw HttpsError("resource-exhausted", "Please wait at least 15 minutes between syncs. Last synced: {timeAgo}")
   - Call `syncFeedForUser(uid, feedUrl)`
   - Return the result `{ synced, removed }`
   - Wrap in try/catch: if syncFeedForUser throws, return HttpsError("internal", error message)

6. **Add scheduledShowingTimeSync scheduled function** (onSchedule):
   - Config: `{ schedule: "every 30 minutes", region: "us-central1", timeoutSeconds: 300 }`
   - Query all users with non-null showingTimeFeedUrl: `db.collection("users").where("showingTimeFeedUrl", "!=", null).get()`
   - For each user: check rate limit (showingTimeLastSyncedAt < 15 min ago -> skip), then call syncFeedForUser in try/catch (log error, continue to next user on failure)
   - Log summary: total users processed, total synced, total errors

**IMPORTANT:** Use `const admin = require("firebase-admin");` at the top of syncFeedForUser for `admin.firestore.Timestamp.fromDate()`. The `admin` import is already available via `initializeApp()` -- access it through `require("firebase-admin")`.

**IMPORTANT:** The `ical = require("node-ical")` should be required inside syncFeedForUser (lazy require to avoid cold start cost when other functions are invoked).
