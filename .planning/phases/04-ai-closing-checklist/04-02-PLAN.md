**Extend js/checklist.js with rendering and interaction functions.**

Add the following to the existing `js/checklist.js` module (after the seeding functions from Plan 01):

**Imports needed** (add to existing imports at top):
```javascript
import { db, auth } from "./firebase-config.js";
import { collection, doc, updateDoc, addDoc, onSnapshot, serverTimestamp }
  from "https://www.gstatic.com/firebasejs/10.8.0/firebase-firestore.js";
import { showToast, escapeHtml, formatDate } from "./auth.js";
```

**Module state:**
```javascript
let checklistItems = [];
let checklistUnsubscribe = null;
let currentClientId = null;
let currentClientData = null;
```

**1. initChecklist(clientId, clientData) function:**
- Stores clientId and clientData in module state
- Calls `subscribeChecklist(clientId)` to set up real-time listener
- Shows/hides empty state vs content based on whether clientData.transactionType exists
- Export this function

**2. subscribeChecklist(clientId) function (internal):**
- If checklistUnsubscribe exists, call it first (cleanup previous listener)
- Set up `onSnapshot` on `collection(db, "clients", clientId, "closingChecklist")`
- On each snapshot: rebuild `checklistItems` array from docs, then call `renderChecklist()`
- Follow the exact pattern from client-detail.js complianceDocs onSnapshot (line ~2903)

**3. renderChecklist() function:**
- If no checklistItems, show empty state div, hide content div, return
- Show content div, hide empty state div
- Group items by category (`pre_contract`, `under_contract`, `closing`)
- Sort items within each category by `sortOrder`

- **Overall progress bar** (rendered into `#checklist-overall-progress`):
  - Total = items where `!notApplicable`
  - Done = items where `completed && !notApplicable`
  - Percentage = `Math.round((done / total) * 100)` or 0 if total is 0
  - HTML: div with class `gd-checklist-overall` containing header row ("Closing Progress" + "X/Y (Z%)") and progress bar

- **Per-category sections** (rendered into `#checklist-categories`):
  For each category (in order: pre_contract, under_contract, closing):
  - Category header with label (from CATEGORY_LABELS) and progress text (done/total)
  - Category progress bar (same structure as overall, using `.gd-checklist-category-progress`)
  - List of checklist items in this category

- **Each checklist item HTML:**
```html
<div class="gd-checklist-item {completed?'completed':''} {notApplicable?'na':''}" data-item-id="{id}">
  <input type="checkbox" class="gd-checklist-check"
    {completed?'checked':''}
    {notApplicable?'disabled':''}
    onchange="window.toggleChecklistItem('{id}', this.checked)">
  <div class="gd-checklist-item-content">
    <span class="gd-checklist-task">{escapeHtml(task)}</span>
    <div class="gd-checklist-item-meta">
      {autoCompleted ? '<span class="gd-badge gd-badge-auto-completed">Auto-completed</span>' : ''}
      {notApplicable ? '<span class="gd-badge gd-badge-na">N/A</span>' : ''}
      {isCustom ? '<span class="gd-badge gd-badge-custom">Custom</span>' : ''}
      {deadline ? '<span class="gd-checklist-deadline {overdue?'overdue':''}">Due: {formatDate(deadline)}</span>' : ''}
    </div>
    <div class="gd-checklist-notes-area" id="notes-{id}">
      <textarea placeholder="Add notes..." onblur="window.saveChecklistNotes('{id}', this.value)">{escapeHtml(notes)}</textarea>
    </div>
  </div>
  <div class="gd-checklist-actions">
    <button class="gd-checklist-action-btn" onclick="window.toggleChecklistNotes('{id}')" title="Notes">&#128221;</button>
    {isSeeded ? '<button class="gd-checklist-action-btn" onclick="window.toggleChecklistNA(\'{id}\')" title="Mark N/A">N/A</button>' : ''}
    {isCustom ? '<button class="gd-checklist-action-btn" onclick="window.deleteChecklistItem(\'{id}\')" title="Delete">&#128465;</button>' : ''}
  </div>
</div>
```
  - Overdue detection: `item.deadline && (typeof item.deadline.toDate === 'function' ? item.deadline.toDate() : new Date(item.deadline)) < new Date()`
  - Export renderChecklist

**4. window.toggleChecklistItem(itemId, checked) function:**
- Find item in checklistItems array
- If unchecking an auto-completed item: also set `autoCompleted: false, autoCompletedAt: null` (per locked decision: "auto-completed badge clears on uncheck")
- Update Firestore: `updateDoc(doc(db, "clients", currentClientId, "closingChecklist", itemId), { completed: checked, completedAt: checked ? serverTimestamp() : null, completedBy: checked ? auth.currentUser?.uid : null, ...(was autoCompleted and now unchecked ? { autoCompleted: false, autoCompletedAt: null } : {}) })`
- The onSnapshot listener will handle re-render

**5. window.toggleChecklistNotes(itemId) function:**
- Toggle the `.open` class on `#notes-{itemId}` element
- Focus the textarea if opening

**6. window.saveChecklistNotes(itemId, value) function:**
- Update Firestore: `updateDoc(doc(db, "clients", currentClientId, "closingChecklist", itemId), { notes: value })`
- Silent save (no toast for notes -- too frequent)

**7. window.toggleChecklistNA(itemId) function:**
- Find item, toggle `notApplicable` field
- If marking as N/A: also set `completed: false, autoCompleted: false`
- Update Firestore with new values
- Toast: "Marked as N/A" or "Removed N/A marking"

**8. window.showAddChecklistItem() function:**
- Toggle `.open` class on the add-form div
- Render a small form inside `.gd-checklist-add-form` with: task text input, category select (3 options), and Save/Cancel buttons

**9. window.saveCustomChecklistItem() function:**
- Read task text and category from form inputs
- Validate task is not empty
- Add to Firestore with `addDoc(collection(db, "clients", currentClientId, "closingChecklist"), { task, category, completed: false, autoCompleted: false, autoCompletedAt: null, notApplicable: false, notes: "", sortOrder: 999, transactionSide: "both", propertyTypes: [], linkedTemplateId: null, isCustom: true, isSeeded: false, deadlineOffsetDays: null, deadline: null, seededAt: null, completedAt: null, completedBy: null })`
- Toast "Custom item added"
- Close the add form

**10. window.deleteChecklistItem(itemId) function:**
- Only allowed for custom items (`isCustom: true`)
- Confirm with `window.confirm("Delete this custom checklist item?")`
- Delete from Firestore: `deleteDoc(doc(db, "clients", currentClientId, "closingChecklist", itemId))`
- Toast "Item deleted"

**11. destroyChecklist() function (exported):**
- Unsubscribes the onSnapshot listener
- Clears module state
