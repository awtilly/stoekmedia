  <name>Task 1: Rewrite service worker to network-first for HTML</name>
  <files>sw.js</files>
  <action>
Rewrite sw.js completely. Keep the same install and activate lifecycle handlers but change the fetch handler strategy:

1. **CACHE_NAME**: Bump to 'mm-draft-v4' (triggers old cache cleanup on activate).

2. **PRECACHE_URLS**: Keep the same 4 URLs: './', './index.html', and the two Firebase CDN scripts.

3. **install handler**: Same as current -- precache static assets, skipWaiting().

4. **activate handler**: Same as current -- delete old caches, clients.claim().

5. **fetch handler**: Replace the current cache-first-for-everything with:
   - **Pass-through** (no respondWith): Firestore API calls where hostname includes 'firestore.googleapis.com', 'firebaseio.com', or (hostname includes 'firebase' AND pathname includes '/documents/'). Just `return;` for these.
   - **Network-first for navigation** (`event.request.mode === 'navigate'`): Try fetch first. On success, clone the response, put the clone in cache, return the original. On network failure (catch), fall back to `caches.match('./index.html')`.
   - **Cache-first for everything else** (CDN scripts, icons, images): Try caches.match first. If cached, return it. If not cached, fetch from network, and if response.ok AND method is GET, clone and cache it, then return the response. On complete failure, fall back to `caches.match('./index.html')`.

Use the exact code from the research document (Pattern 1 / Code Examples section) as the implementation reference. The full SW should be ~50 lines.
